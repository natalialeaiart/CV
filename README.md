# HTML CV Template — One Page, Print-Ready

A clean, responsive CV page built with pure HTML and CSS. No frameworks, no dependencies. Works in the browser, looks great on mobile, and prints as a professional one-page PDF.

---

## What's included

- Responsive layout — desktop and mobile
- Print-ready styling — A4, no browser headers or footers
- Download PDF button
- Click-to-copy email
- Sections: Hero with photo, Skills, Languages, Experience, Education
- Optional footer link to portfolio or another page (hidden in print)

---

## How to make your own version using Claude

You don't need to know HTML. Just follow these steps.

### What you'll need

- Your CV as a PDF or Word file
- Your photo (portrait, any format)
- A [Claude.ai](https://claude.ai) account (free plan works)
- A [GitHub](https://github.com) account (free)

---

### Step 1 — Download this template

Click **Code → Download ZIP** on this repository page and unzip it.
You'll get: `index.html`, a photo file, `cv.pdf`, and this `README.md`.

---

### Step 2 — Open Claude and send this prompt

Go to [claude.ai](https://claude.ai), start a new conversation, and attach **three files**:
1. Your CV (PDF or Word)
2. Your photo
3. The `index.html` file from this template

Then paste this prompt:

---

> I want to create a personal CV webpage similar to the attached `index.html` template.
>
> Here is my CV (attached) and my photo (attached).
>
> Please build me a new `index.html` based on the same design and structure as the template, but with my own information. Use my CV data to fill in all sections: name, job title, summary, contacts, skills, experience, education, and languages.
>
> A few requirements:
> - Keep the same visual style, layout, and color scheme as the template
> - Place my photo in the hero section the same way
> - The page must be responsive — look good on mobile and desktop
> - It must be print-ready: one A4 page, no browser headers in print, cards should not break across pages
> - Include a Print CV button and a Download PDF button (the PDF button should link to `cv.pdf` and download with my full name as the filename)
> - The email should be click-to-copy, not a mailto link
> - Hide the footer link section in print
>
> If anything in my CV is unclear or missing, ask me before generating.
>
> Also ask me what accent color I prefer for the design — or suggest a few options based on my photo.

---

### Step 3 — Save your files

Claude will generate a new `index.html`. Download it and put these four files in one folder:

```
your-cv/
├── index.html       ← generated by Claude
├── photo.jpg        ← your photo (same filename as referenced in the HTML)
├── cv.pdf           ← you'll create this in the next step
└── README.md
```

---

### Step 4 — Create your PDF

1. Open `index.html` in **Chrome** or **Edge**
2. Press `Ctrl+P` (or `Cmd+P` on Mac)
3. Destination: **Save as PDF**
4. Click **More settings**:
   - Paper size: A4
   - Margins: Default
   - **Headers and footers: turn OFF** ← this removes the date and URL from the PDF
5. Save the file as `cv.pdf` into the same folder

---

### Step 5 — Publish on GitHub Pages

1. Create a new repository on GitHub (e.g. named `cv`)
2. Upload all four files
3. Go to **Settings → Pages**
4. Source: **Deploy from a branch** → `main` → `/ (root)`
5. Your CV will be live at `https://yourusername.github.io/cv`

---

## Tips

- **Photo**: portrait orientation works best. The template applies grayscale automatically — a color photo is fine.
- **One page**: if the CV spills onto a second page when printing, ask Claude to shorten the bullet points or reduce the number of experience entries.
- **Colors**: the template uses a burgundy accent by default. Ask Claude to change it — just say something like *"use navy blue"* or *"I want a dark green accent"*. You can also ask Claude to suggest colors that work well with your photo. All colors are CSS variables, so one change reskins the whole page. Some combinations that work well:
  - Burgundy / plum `#7B2D42` — classic, elegant (default)
  - Navy `#1B3A6B` — corporate, trustworthy
  - Forest green `#2D5A3D` — calm, grounded
  - Slate blue `#3D4E6B` — modern, neutral
  - Warm charcoal `#3A3230` — minimal, timeless
- **Language**: ask Claude to generate the page in any language you need.
